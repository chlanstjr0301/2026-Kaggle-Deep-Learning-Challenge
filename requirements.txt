# ── 절대 규칙 ────────────────────────────────────────────────
# 고정 상수는 "드라이버"다. torch도 vllm도 변수다.
#
#   드라이버 CUDA >= 13.0 (= 드라이버 580+)
#       -> torch 2.13.0 (cu130) + vllm 0.27.x.  PyPI 기본 조합이 그대로 맞음.
#          pip 명령에 --index-url 을 붙이지 말 것. 붙이면 cu128을 끌어와서
#          vllm wheel(cu13 빌드)과 어긋나 libcudart.so.13 에러가 난다.
#
#   드라이버 CUDA < 13.0 (= 드라이버 570 등)
#       -> vllm PyPI wheel 자체가 못 뜬다. 버전 조합으로 해결 불가.
#          호스트를 바꿔야 한다. bootstrap.sh step 0이 여기서 끊는다.
#
# 확인:  nvidia-smi 의 "CUDA Version"  vs  python -c "import torch;print(torch.version.cuda)"
#        이 둘의 major 가 같아야 하고, vllm wheel 도 같은 major 여야 한다.
# ─────────────────────────────────────────────────────────────
